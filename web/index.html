Cómo funciona el laboratorio
El navegador interpreta un subconjunto educativo de Java: variables, control de flujo, métodos, arreglos y POO. Los robots son clases de nuestra API. El archivo descargable contiene Java completo para ejecutar la misma misión con un JDK. El avance se guarda en tu cuenta; las pruebas y borradores permanecen en la sesión actual.
